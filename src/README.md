# CareerConnect

**CareerConnect** is a sleek and intuitive job application tracker that helps job seekers stay organized, search for job opportunities, and track the status of their applications with real-time insights.

## 🚀 Features

- **🔍 Job Search** – Find job roles easily within the app.
- **📋 Application Tracker** – Add, edit, and monitor job applications.
- **📊 Dashboard & Charts** – Visualize your progress with charts using Chart.js.
- **👤 User Profile** – Manage your personal details and job history.
- **⚙️ Settings** – Customize your user experience.
- **📱 Responsive UI** – Optimized for both desktop and mobile.

## 🛠️ Tech Stack

- **React** – Frontend library
- **TailwindCSS** – Utility-first CSS for responsive design
- **Chart.js + react-chartjs-2** – Data visualization
- **React Router DOM** – Routing and navigation

## 📦 Installation

To run this project locally:

```bash
# Step 1: Clone the repository
git clone https://github.com/manishakumari02/CareerConnect.git
cd CareerConnect

# Step 2: Install dependencies
npm install

# Step 3: Run the development server
npm run dev

# Step 4: Open the app in your browser
http://localhost:3000
